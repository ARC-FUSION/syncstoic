# Contributing to SyncFocus

Thank you for your interest in contributing to SyncFocus! This document provides guidelines and information for contributors.

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/syncfocus.git
   cd syncfocus
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## 🛠️ Development

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Code Style

- Use TypeScript for all new files
- Follow existing code formatting (Prettier)
- Write meaningful commit messages
- Add comments for complex logic
- Keep components focused and small

## 🔄 Pull Request Process

1. Update the README.md with details of changes if needed
2. Ensure your code passes all linting checks
3. Update documentation as needed
4. Submit your pull request with a clear description

## 🐛 Reporting Bugs

Use GitHub Issues to report bugs. Please include:
- Clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
- Environment details (OS, browser, Node version)

## 💡 Feature Requests

We welcome feature requests! Please:
- Check existing issues first
- Use a clear and descriptive title
- Provide detailed description
- Explain the use case

## 🤝 Code of Conduct

- Be respectful and inclusive
- Focus on what's best for the community
- Accept constructive criticism
- Show empathy towards other contributors

Thank you for contributing to SyncFocus! 🎉
